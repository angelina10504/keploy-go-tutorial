# Keploy + Go on macOS

A tutorial for Keploy's Gin + MongoDB quickstart, run natively on an Apple Silicon Mac.

**Live:** https://keploy-go-tutorial-seven.vercel.app

**Built with:** Next.js, MDX, Tailwind CSS, Shiki

## Run locally

```bash
git clone https://github.com/angelina10504/keploy-go-tutorial.git
cd keploy-go-tutorial
npm install
npm run dev
```

Then open http://localhost:3000.

The tutorial content lives in `app/page.mdx`.
