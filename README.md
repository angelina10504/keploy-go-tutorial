# Keploy + Go on macOS

A single-page tutorial on running Keploy's Gin + MongoDB quickstart natively on an Apple Silicon Mac, built with Next.js and MDX.

**Live:** <vercel-link>

## Stack
- Next.js 16 (App Router, Turbopack) with `@next/mdx`
- Tailwind CSS v4 + `@tailwindcss/typography`
- Syntax highlighting: `rehype-pretty-code` + Shiki (light/dark themes)
- Custom MDX components: `Callout`, `Steps`, `FlowDiagram`, copy-to-clipboard code blocks, "On this page" sidebar, dark/light toggle

## Run locally
npm install
npm run dev

The tutorial content lives in `app/page.mdx`.
